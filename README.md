# NOVA — сайт Garry's Mod сервера

Одностраничный сайт без сборки и зависимостей: HTML + CSS + JS. Все картинки нарисованы в SVG, шрифты лежат локально.

## Запуск

Открой `index.html` в браузере или подними любой статический сервер:

```bash
npx http-server -p 8080
```

Для хостинга подойдёт GitHub Pages, Netlify, Vercel или обычный nginx: просто залей файлы.

## GitHub Pages

Сайт открывается по адресу **https://aloxins.github.io/pidr/**, когда Pages включён:

1. Репозиторий должен быть публичным (на бесплатном аккаунте Pages не работает с приватными):
   **Settings → General → Danger Zone → Change visibility → Make public**.
2. **Settings → Pages → Build and deployment**:
   Source: **Deploy from a branch**, Branch: `claude/gmod-server-website-51loz5`, папка `/ (root)` → **Save**.
3. Подожди 1–2 минуты, и сайт появится по ссылке выше. Статус сборки видно во вкладке **Actions**.

После этого каждый пуш в эту ветку автоматически обновляет сайт. Файл `.nojekyll` отключает обработку Jekyll, чтобы GitHub отдавал файлы как есть.

## Настройка

Всё, что относится к серверу, лежит в объекте `CONFIG` в начале `js/main.js`:

| Поле         | Что это                                                            |
|--------------|--------------------------------------------------------------------|
| `name`       | Название сервера (подставляется в заголовок, меню, футер)          |
| `ip`         | IP:порт. Кнопки «Играть» открывают `steam://connect/<ip>`          |
| `discord`    | Ссылка-приглашение в Discord                                       |
| `maxPlayers` | Количество слотов                                                  |
| `map`        | Карта, которая показывается в статусе                              |
| `statusUrl`  | URL с JSON `{ "online": 42, "max": 64, "map": "..." }`             |
| `typer`      | Фразы для анимированной строки в шапке                             |
| `team`       | Команда (аватарки генерируются автоматически из имени)             |

Пока `statusUrl` пустой, онлайн **демонстрационный**. Браузер не умеет сам опрашивать Source-сервер (протокол A2S работает по UDP), поэтому для настоящего онлайна нужен маленький бэкенд или сторонний сервис мониторинга, который отдаёт JSON.

Тексты режимов, правил, доната и FAQ правятся прямо в `index.html`.

## Что внутри

- **Шрифты:** Unbounded (заголовки), Manrope (текст), JetBrains Mono (IP и теги). Все с кириллицей, лицензия OFL.
- **Картинки** (`assets/img`, `assets/props`): логотип, 4 сцены режимов, 2 кадра для галереи, пропы для шапки (арбуз, ящик, бочка, конус), превью для соцсетей `og.jpg`.
- **Анимации:** прелоадер с отрисовкой логотипа, canvas с частицами и неоновой сеткой в стиле synthwave, буквы заголовка вылетают по одной, глитч-эффект, печатающийся текст, параллакс пропов за мышкой, кастомный курсор, магнитные кнопки, 3D-наклон карточек с бликом, появление блоков при скролле, счётчики, бегущая строка, вращающаяся рамка у тарифа PREMIUM, галерея с перетаскиванием и лайтбоксом.
- Учитывается `prefers-reduced-motion`: если в системе отключены анимации, сайт их тоже отключает.

## Структура

```
index.html
favicon.svg
css/style.css     — стили и анимации
css/fonts.css     — подключение локальных шрифтов
js/main.js        — CONFIG и вся интерактивность
assets/img/       — логотип, сцены, og-превью
assets/props/     — пропы для шапки
assets/fonts/     — woff2 (кириллица + латиница)
```
